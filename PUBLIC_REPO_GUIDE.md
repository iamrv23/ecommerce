### **4. How People Can Contribute**

#### **Contributors Will:**

1. **Fork your repository**
   - Click "Fork" button on GitHub
   - Creates their own copy

2. **Create feature branch**
   - `git checkout -b feature/awesome-feature`

3. **Make changes & commit**
   - Follow [CONTRIBUTING.md](CONTRIBUTING.md)

4. **Push and create Pull Request**
   - Click "Compare & pull request"
   - Fill in PR description

5. **You review & merge**
   - Check code quality
   - Run tests
   - Merge to development

## 📋 What Your README Should Highlight for Contributors

### **Add this section to README.md:**

```markdown
## 🤝 Contributing

We welcome contributions! To contribute:

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/your-feature`
3. **Make your changes** (following [CONTRIBUTING.md](CONTRIBUTING.md))
4. **Add tests** for new features
5. **Commit with clear messages**: `git commit -m "feat: add feature"`
6. **Push to your fork**: `git push origin feature/your-feature`
7. **Create a Pull Request** describing your changes

### Requirements:
- Follow PSR-12 / Yii2 conventions
- Add unit tests
- Update documentation
- One feature per PR
- Reference any related issues

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed guidelines.
```
